# 機能要件

## 機能一覧
- カードの追加(タイトル・説明・優先度・期限を入力して作成)
- カードの削除
- カードのドラッグ&ドロップによる列間移動
- カードの登録・更新・削除はAPI経由でPostgreSQLに永続化され、再読み込み後も内容を保持する

## カード項目定義
| 項目 | 必須/任意 | 内容 |
|---|---|---|
| タイトル | 必須 | タスク名 |
| 説明文 | 任意 | タスクの詳細 |
| 優先度 | 任意 | 低 / 中 / 高 から選択 |
| 期限 | 任意 | 日付を選択 |

## 非機能要件
- 性能: カードの追加・削除・移動などの操作結果は、API経由で即座にPostgreSQLへ反映されること
- セキュリティ: 個人情報は扱わない前提とし、学習用途のためログイン認証は対象外とする
- 可用性・保守性: 学習目的のアプリのため、本番運用を想定した可用性・保守性要件は対象外とする
